🛒 Sistema de Vendas — Jornada Python
Sistema de vendas desenvolvido durante a Jornada Python, com o objetivo de praticar conceitos de programação, organização de projetos e desenvolvimento de aplicações em Python.

📌 Sobre o projeto
O projeto consiste em um sistema para gerenciamento de vendas, permitindo organizar informações relacionadas aos produtos e às operações de venda.

Este projeto foi desenvolvido como parte dos estudos e exercícios realizados durante a Jornada Python.

🚀 Tecnologias utilizadas
🐍 Python

🗄️ Banco de dados

💻 Pandas

🔧 Streamlit
